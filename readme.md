## Суть задания

В приложении **TalkZone** (чат-приложение) сейчас используется стандартный `alert()` для запроса имени пользователя. Нужно заменить это на **кастомное модальное окно**, которое запрашивает **Username** и **Возраст** при первом входе.

---

## Текущая проблема

```javascript
// ❌ Сейчас так (плохо):
const username = prompt("Введите ваше имя");
```

---

## Что нужно сделать

### 1️⃣ Создать модальное окно

```
┌─────────────────────────────────┐
│      Добро пожаловать в        │
│         TalkZone! 💬            │
├─────────────────────────────────┤
│                                 │
│  Username:                      │
│  [________________]             │
│                                 │
│  Возраст:                       │
│  [________________]             │
│                                 │

---

### 2️⃣ Требования к форме

| Поле | Валидация |
|------|-----------|
| **Username** | Минимум 3 символа, только буквы и цифры |
| **Возраст** | Число от 10 до 99 |

**Обработка ошибок:**
- Показывать текст ошибки красным под полем
- Кнопка "Войти" неактивна, пока форма невалидна
- Нельзя закрыть модалку без заполнения

---

### 3️⃣ После входа

│  [Сообщения чата]               │

```

**В сообщениях:**

## 📋 Пример кода

### HTML структура:
```html
<div id="modal-overlay" class="modal-overlay">
  <div class="modal">
    <h2>Добро пожаловать в TalkZone! 💬</h2>
    
    <div class="form-group">
      <label>Username:</label>
      <input type="text" id="username" placeholder="Например: Alex_2024">
      <span class="error" id="username-error"></span>
    </div>
    
    <div class="form-group">
      <label>Возраст:</label>
      <input type="number" id="age" placeholder="18">
      <span class="error" id="age-error"></span>
    </div>
    
    <button id="submit-btn" disabled>Войти в чат</button>
  </div>
</div>
```

### Валидация:
```javascript
function validateUsername(username) {
  if (username.length < 3) {
    return "Минимум 3 символа";
  }
  if (!/^[a-zA-Z0-9_]+$/.test(username)) {
    return "Только буквы, цифры и _";
  }
  return null;
}

function validateAge(age) {
  if (age < 10 || age > 99) {
    return "Возраст должен быть от 10 до 99";
  }
  return null;
}
```
