<h1>🏦 Задание: Поиск подозрительных клиентов банка по сумме переводов (JavaScript)</h1>

Представьте, что вы — команда разработчиков антифрод‑системы в банке.
Ваша задача — написать функцию, которая находит всех клиентов, у которых суммарный объём переводов за месяц превысил заданный порог, и возвращает их в отдельном массиве для последующей блокировки.

🧾 Исходные данные
У вас есть массив клиентов, каждый клиент — объект с информацией о переводах за текущий месяц:

<pre>
const clients = [
  {
    id: 1,
    name: "Иван Иванов",
    transfers: [
      { amount: 20000, date: "2026-04-01" },
      { amount: 50000, date: "2026-04-10" },
      { amount: 40000, date: "2026-04-21" }
    ]
  },
  {
    id: 2,
    name: "Мария Петрова",
    transfers: [
      { amount: 10000, date: "2026-04-03" },
      { amount: 15000, date: "2026-04-18" }
    ]
  },
  // ... Сгенерируйте еще 50 таких объектов
]
  
</pre>

<code>transfers</code> — массив переводов за месяц для одного клиента.

<code>amount</code> — сумма одного перевода в рублях.

🎯 Задача функции
Реализуйте функцию:
<pre>
function findClientsOverLimit(clients, limit) {
  // ...
}
</pre>
Функция должна:

Пройти по всем клиентам.

Для каждого клиента посчитать общую сумму всех переводов за месяц.

Если сумма строго больше <code>limit</code>, считать клиента подозрительным.

Вернуть новый массив, в который входят только те клиенты, у которых сумма переводов за месяц > <code>limit</code>.
<pre>
  const suspiciousClients = findClientsOverLimit(clients, 100000);
</pre>
