<h1>🪙 Тема:Алгоритмы поиска и работа с массивами объектов </h1>
Вам необходимо создать массив пользователей, в котором будет храниться информация о 100 людях.

Каждый пользователь должен быть представлен в виде объекта.

В объекте должны храниться следующие данные:

id пользователя

имя пользователя

статус заражения коронавирусом

В массиве только один пользователь заражён коронавирусом.

Ваша задача — написать алгоритм, который найдёт заражённого пользователя.

Однако есть важное условие:

⚠️ Ваш алгоритм должен найти заражённого меньше чем за 10 операций проверки.

Это означает, что перебирать всех пользователей через обычный цикл нельзя, потому что это займёт до 100 операций.

Пример объекта пользователя
<pre>
  const user = {
  id: 1,
  name: "Serkan",
  hasCorona: false
}
</pre>

Пример массива пользователей
<pre>
const users = [
  { id: 1, name: "Alex", hasCorona: false },
  { id: 2, name: "Maria", hasCorona: false },
  { id: 3, name: "John", hasCorona: false },
  { id: 4, name: "Kate", hasCorona: true },
]
</pre>


Только один пользователь должен иметь:

hasCorona: true

Написать функцию:

findInfectedUser(users)


Необходимо придумать более эффективный алгоритм поиска.

##Функция должна вернуть объект заражённого пользователя.
