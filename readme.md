<h1>📝 Тема: Разработка веб-приложения для планирования питания с интеграцией Telegram-бота на HTML, CSS и JavaScrip</h1>

Example: Telegram Meal Planner App
Описание задачи:
Необходимо создать веб-приложение, которое позволяет пользователю получать сбалансированный план питания на день через Telegram-бота. Пользователь взаимодействует с веб-приложением, нажимает кнопку «Спланировать питание», после чего Telegram-бот автоматически отправляет персонализированный режим питания на весь день на указанный Telegram ID.

В приложении должно быть отображено сообщение «План питания отправлен на ваш Telegram аккаунт», чтобы пользователь понимал, что запрос обработан.

Приложение должно включать удобный интерфейс для выбора типа питания (например, стандартный, для похудения, для набора массы) и визуальные элементы, отображающие успешную отправку плана.
