<h1>🪙 Тема: Создание криптовалютного приложения (Mini Binance) с использованием бесплатного Crypto API </h1>

Example: Необходимо разработать одностраничное приложение, которое получает официальные данные о криптовалютах из бесплатного публичного API (например, CoinGecko API) и отображает их в виде торговой таблицы, похожей на интерфейс Binance.
Приложение должно имитировать базовый интерфейс криптобиржи и работать с реальными данными.
Основная цель — научиться работать с API, состоянием приложения и динамическим отображением данных.
Отображать список минимум 20 криптовалют
